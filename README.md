# Clients_simalee

Сайт: https://simaleee.github.io/Clients_simalee/

После нажатия на Simalee откройте «Разработка игр». В разделе доступна Soryy: запуск WebGL на странице, открытие в отдельной вкладке и скачивание Android APK.

Готовая браузерная игра размещается отдельно: https://simaleee.github.io/Soryy-web/. Тяжёлая Unity-сборка не хранится в этом репозитории и загружается только по нажатию «Играть в браузере». Кнопка «К разделам» останавливает игру и возвращает меню.

Публикация GitHub Pages: ветка main, корень репозитория. Для отката раздела можно отменить коммит с добавлением игры.
